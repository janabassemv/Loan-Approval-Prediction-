# Loan-Approval-Prediction-
This project builds a machine learning model to predict whether a loan application will be approved or rejected based on applicant details such as income, loan amount, CIBIL score, and asset values.

## 🔹 Features
- ✅ Data cleaning and preprocessing  
  - Handled missing values  
  - Encoded categorical features  
- ✅ Dealt with **imbalanced dataset** using XGBoost’s 
- ✅ Trained a **binary classification model (XGBoost)**  
- ✅ Evaluated using **accuracy, precision, recall, and F1-score**  

---


## 🔹 Tech Stack
- **Python**  
- **Pandas** (data preprocessing)  
- **Scikit-learn** (encoding, splitting, evaluation)  
- **XGBoost** (model training)
